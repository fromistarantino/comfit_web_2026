# 이벤트 참여 내용 받아 보기 (Google 스프레드시트 + 드라이브)

참여 페이지(`join.html`)에서 누군가 제출하면 이렇게 됩니다.

- **내 Google 스프레드시트**에 한 줄이 생깁니다: 접수번호, 시각, 닉네임, 이메일, 설문 답, 소식 수신 동의, 리포트 링크
- 첨부한 **리포트 파일**은 내 Google 드라이브의 `COMFIT 이벤트 리포트` 폴더에 저장됩니다
- (켜 두면) 접수될 때마다 **내 Gmail로 알림 메일**이 옵니다

비용은 없습니다. 처음 설정은 10분쯤 걸리고, 한 번만 하면 됩니다.

---

## 1. 스프레드시트 만들기

1. 운영용 Google 계정으로 <https://sheets.new> 를 엽니다.
2. 왼쪽 위 제목을 `COMFIT 이벤트 접수`로 바꿉니다.

## 2. 접수 코드 붙여 넣기

1. 스프레드시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 처음 보이는 `Code.gs`의 내용을 **전부 지우고**, 이 저장소의 [`tools/apps-script/Code.gs`](../tools/apps-script/Code.gs) 내용을 통째로 붙여 넣습니다.
   (GitHub에서 파일을 연 뒤 오른쪽 위 복사 버튼을 누르면 전체가 복사됩니다.)
3. 저장(디스크 아이콘 또는 `Ctrl+S`)합니다.
4. 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다.
   - "승인 필요" 창이 뜨면 **권한 검토 → 내 계정 선택**을 누릅니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동**을 누른 뒤 **허용**을 누릅니다.
     직접 만든 스크립트라 이 화면이 뜨는 것이 정상입니다.
   - 아래 실행 로그에 `준비 완료`가 나오면 성공입니다. 스프레드시트에 `접수` 시트가 생기고 드라이브에 폴더가 생깁니다.

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. 이렇게 맞춥니다.
   - 설명: `COMFIT 이벤트 접수`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** ← 로그인 없이 참여할 수 있게 하려면 꼭 이 값이어야 합니다
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> "모든 사용자"는 *이 주소로 접수를 보낼 수 있다*는 뜻입니다. 시트와 드라이브 파일은 여전히 나만 볼 수 있습니다.

## 4. 사이트에 주소 넣기

1. GitHub 저장소에서 `web/config.js`를 엽니다 → 연필(✏️) 아이콘.
2. 이 줄의 따옴표 안에 복사한 주소를 붙여 넣습니다.
   ```js
   formEndpoint: 'https://script.google.com/macros/s/여기에-받은-주소/exec',
   ```
3. **Commit changes**를 누르면 2~3분 뒤 사이트에 반영됩니다 (Actions 탭에서 진행 상황 확인).

## 5. 시험해 보기

1. 사이트의 `join.html`에서 내 이메일로 한 번 제출해 봅니다 (아무 PDF나 JSON 파일 첨부).
2. "참여가 완료되었습니다"와 접수번호가 보이고, 스프레드시트에 한 줄이 생기면 끝.
3. 시험한 줄은 스프레드시트에서 지워도 됩니다. 같은 이메일로 다시 시험하려면 그 줄을 지우세요(1인 1회 제한).

## 운영하면서

| 하고 싶은 것 | 방법 |
|---|---|
| 참여 목록 보기 | 스프레드시트의 `접수` 시트. 필터·정렬을 마음대로 쓰세요 |
| 리포트 열기 | 시트의 "리포트 링크" 칸을 누르면 드라이브에서 열립니다 (나만 열림) |
| 추첨 | 시트에서 `=INDEX(D2:D, RANDBETWEEN(1, COUNTA(D2:D)))` 처럼 뽑거나 따로 추첨 도구 사용 |
| 접수 마감 | `web/config.js`에서 `eventOpen: false` (화면 막기) **그리고** Apps Script `SETTINGS.OPEN = false` 후 다시 배포 (서버도 막기) |
| 알림 메일 끄기 | Apps Script `SETTINGS.NOTIFY = false` 후 다시 배포 |
| 파일 크기 한도 바꾸기 | Apps Script `MAX_FILE_MB`와 `web/config.js`의 `maxFileMB`를 같은 값으로 |
| 개인정보 파기 | 보유 기간이 끝나면 시트와 드라이브 폴더를 지우고 **휴지통도 비우세요** |

### Apps Script 코드를 고친 뒤 다시 배포하는 법 (주소 유지)

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. 이렇게 하면 웹 앱 주소가 바뀌지 않습니다.
"새 배포"를 다시 누르면 주소가 바뀌니, 그때는 `config.js`의 주소도 바꿔야 합니다.

### 이미 넣어 둔 보호 장치

- 숨은 칸(봇 덫): 자동 프로그램이 채우면 저장하지 않음
- 이메일당 1회, 1시간 최대 300건 (스팸이 몰릴 때 막는 장치)
- 허용한 파일 형식만 받고, 확장자와 내용이 다르면 거부 (예: `.pdf`로 이름만 바꾼 실행 파일)
- 시트에 `=`, `+`, `-`, `@`로 시작하는 글은 수식이 아닌 글자로 저장 (수식 주입 방지)
- 설문 답은 정해진 보기만 저장

### 주의

- 첨부 파일은 모르는 사람이 올린 파일입니다. **zip을 풀거나 html을 내 PC에서 열 때 조심하세요.** 드라이브 미리보기로 보는 것이 가장 안전합니다.
- Gmail 무료 계정의 알림 메일은 하루 100통까지입니다. 넘으면 메일만 안 오고 접수는 정상입니다.
- 스프레드시트·폴더를 다른 사람과 공유하지 마세요. 공유하면 참여자 개인정보가 함께 공유됩니다.
