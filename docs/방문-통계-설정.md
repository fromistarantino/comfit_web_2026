# 방문 통계 보기 (Cloudflare Web Analytics)

사이트에 **몇 명이 들어왔는지, 어느 페이지를 봤는지, 어디서 왔는지**(인스타그램·페이스북·검색 등)를 볼 수 있습니다.
무료이고, 쿠키를 쓰지 않으며 방문자를 개인별로 식별하지 않습니다. 설정은 10분쯤 걸립니다.

> 통계는 **설정을 마친 시점부터** 쌓입니다. 그 전의 방문은 볼 수 없습니다.

## 1. Cloudflare 가입하고 사이트 등록

1. <https://dash.cloudflare.com/sign-up> 에서 이메일과 비밀번호로 가입합니다 (무료, 카드 정보 필요 없음).
2. 가입 뒤 왼쪽 메뉴에서 **Analytics & Logs → Web Analytics**를 엽니다.
   (메뉴가 안 보이면 위 검색창에 `Web Analytics`를 입력)
3. **Add a site**를 누르고 Hostname에 `comfit.kr`을 입력한 뒤 **Done**을 누릅니다.
   - "도메인을 Cloudflare로 옮기라"는 안내가 나오면 따르지 마세요. **Web Analytics만** 쓰면 되고, 도메인 설정은 건드리지 않습니다.
4. 화면에 이런 코드가 나옵니다.
   ```html
   <script defer src='https://static.cloudflareinsights.com/beacon.min.js' data-cf-beacon='{"token": "0123456789abcdef0123456789abcdef"}'></script>
   ```
   여기서 **`token` 뒤의 영문·숫자 32자**만 복사합니다. (코드 전체를 사이트에 붙여 넣지 않습니다)

## 2. 사이트에 토큰 넣기

1. GitHub 저장소에서 `web/config.js`를 엽니다 → 연필(✏️) 아이콘.
2. 이 줄의 따옴표 안에 복사한 32자를 붙여 넣습니다.
   ```js
   analyticsToken: '0123456789abcdef0123456789abcdef',
   ```
3. **Commit changes**를 누르면 2~3분 뒤 사이트에 반영됩니다.

토큰은 비밀번호가 아닙니다. 사이트 화면에 원래 드러나는 값이라 공개되어도 괜찮습니다.

## 3. 통계 보기

<https://dash.cloudflare.com> → **Analytics & Logs → Web Analytics → comfit.kr**

| 보고 싶은 것 | 보는 곳 |
|---|---|
| 방문자 수 | **Visits** (방문 수), **Page views** (페이지 조회 수) |
| 어느 페이지를 봤나 | **Paths** — `/join.html`(이벤트 참여), `/download.html`(다운로드) |
| 어디서 왔나 (광고 효과) | **Referers** — `instagram.com`, `facebook.com`이 광고로 들어온 방문 |
| PC인지 휴대폰인지 | **Device type** |
| 기간 | 오른쪽 위에서 최근 24시간, 7일, 30일 선택 |

반영까지 몇 분 걸립니다. 넣은 직후에는 내 휴대폰으로 사이트를 한 번 열어 보고 5~10분 뒤 숫자가 올라가는지 확인하세요.

## 광고 효과를 읽는 법

| 단계 | 숫자를 보는 곳 |
|---|---|
| 광고를 눌러 들어온 사람 | Web Analytics의 Referers에서 instagram / facebook 방문 수 (광고 대행사의 보고서 "링크 클릭"과 비교) |
| 참여 페이지를 본 사람 | Paths의 `/join.html` |
| 프로그램을 받은 횟수 | GitHub 저장소 → Releases의 설치 파일 다운로드 횟수 |
| 설문까지 제출한 사람 | Google 스프레드시트 `집계` 탭의 전체 응답자 수 |

## 알아 둘 것

- 광고 차단 프로그램을 쓰는 방문자는 세지 않습니다. 실제 방문보다 조금 적게 나옵니다.
- 사람 수가 아니라 **방문 수**입니다. 같은 사람이 여러 번 오면 여러 번 셉니다.
- 통계를 끄려면 `analyticsToken`을 다시 `''`로 비우면 됩니다. 개인정보처리방침의 방문 통계 문구도 자동으로 빠집니다.
