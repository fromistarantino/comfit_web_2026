# 사이트 글 고치는 법

컴퓨터에 아무것도 설치하지 않고 **GitHub 웹사이트에서 바로** 고칠 수 있습니다.
고친 뒤 저장(Commit)하면 2~3분 뒤 PC·모바일 사이트에 함께 반영됩니다. 모바일도 같은 html을 쓰므로 한 번만 고치면 됩니다.

## 0. 기본 순서 (모든 수정에 공통)

1. <https://github.com/fromistarantino/comfit_web_2026> 에서 고칠 파일을 엽니다 (예: `web/config.js`).
2. 오른쪽 위 **연필(✏️) 아이콘**을 누릅니다.
3. `Ctrl+F`로 바꿀 문장을 찾아 고칩니다.
4. 오른쪽 위 **Commit changes… → Commit changes**를 누릅니다.
5. 저장소 위쪽 **Actions** 탭에서 "사이트 배포"가 초록색 ✓가 되면 반영 완료. 빨간 ✗면 아래 "문제가 생기면"을 보세요.
6. 사이트에서 새로고침(모바일은 당겨서 새로고침)으로 확인합니다. 바로 안 바뀌면 1~2분 뒤 다시 보세요.

## 1. 자주 바꾸는 값은 `web/config.js` 한 곳에

| 바꾸고 싶은 것 | config.js 의 이름 |
|---|---|
| 이벤트 이름 / 기간 / 발표일 / 대상 | `eventName`, `eventPeriod`, `eventAnnounce`, `eventTarget` |
| 접수 마감 | `eventOpen: false` |
| 경품 목록 | `prizes` (줄을 늘리거나 줄여도 됨) |
| 검진 프로그램 다운로드 주소, 버전, 크기 | `downloadUrl`, `programVersion`, `programDate`, `programSize`, `programSha256` |
| 이벤트 접수 주소 | `formEndpoint` (→ [이벤트-접수-설정.md](이벤트-접수-설정.md)) |
| 문의 이메일 | `contactEmail` |
| 맨 아래에 더 적을 줄(운영자 정보 등) | `footerLines` |
| 개인정보 보유 기간 문구 | `retention` |

규칙은 간단합니다.

```js
eventPeriod: '2026. 11. 20(금) ~ 11. 30(월)',
//            ↑ 작은따옴표 안의 글자만 바꾸고, 따옴표와 끝의 쉼표는 그대로
```

- 글 안에 작은따옴표(`'`)를 쓰려면 `\'`로 적습니다.
- `downloadUrl`, `formEndpoint`는 `https://`로 시작하는 주소만 받습니다 (보안상 다른 형식은 무시).

## 2. 그 밖의 문장은 각 html 파일에서

페이지와 파일 이름:

| 화면 | 파일 |
|---|---|
| 홈 | `web/index.html` |
| 이벤트 안내 | `web/event.html` |
| 이벤트 참여(양식) | `web/join.html` |
| 검진 / 다운로드 / 검진 안내 / 결과표 예시 | `web/diagnose.html`, `web/download.html`, `web/guide.html`, `web/result.html` |
| SHOP·장터·시세·로그인 등 준비 중 화면 | `web/list.html`, `web/market.html`, `web/price.html`, `web/login.html` … |
| 자주 묻는 질문 / 공지 | `web/help.html`, `web/notice.html` |
| 약관·개인정보처리방침 | `web/terms.html`, `web/privacy.html`, `web/policy.html`, `web/programterms.html` |

html 파일 안에는 세 덩어리가 있습니다.

```
<div id="app"></div>             ← 비어 있음. 건드리지 마세요 (배포 때 자동으로 채움)
<template id="dc"> … </template>  ← ★ 화면의 글은 여기서 고칩니다
<script type="text/plain" id="dc-code"> … </script>  ← 동작 코드 (공지·FAQ 목록 같은 일부 글도 여기 있음)
```

### 고쳐도 되는 것 / 안 되는 것

```html
<h1 id="ev-title" style="margin: 0; font-size: 36px;">PC 건강검진 공모전</h1>
                                                    └──── 여기 글자만 ────┘
```

- **고쳐도 됨**: `>`와 `<` 사이의 글자
- **건드리지 말 것**: `<`, `>`, `"`, `style="…"`, `{{ … }}`, `dc-onclick="{{…}}"`, `<sc-if …>`, `<sc-for …>`
  - `{{cfg.eventPeriod}}`처럼 중괄호 두 개로 된 부분은 config.js 값이 들어가는 자리입니다. 그 값은 config.js에서 바꾸세요.
- 줄바꿈을 넣고 싶으면 문장 사이에 `<br>`를 넣습니다.

### 공지사항·자주 묻는 질문 고치기

`web/help.html`, `web/notice.html`은 목록이 맨 아래 `<script type="text/plain" id="dc-code">` 안에 있습니다.

```js
{ id: 'n1', tag: '공지', title: '제목은 여기', body: '본문은 여기' },
```

작은따옴표 안의 글자만 바꾸세요. 줄 끝의 `},` 와 `,` 를 지우면 화면이 깨집니다.

## 3. 사진 바꾸기

1. 새 사진을 `web/assets/`에 올립니다: 폴더를 열고 **Add file → Upload files**.
2. html에서 바꿀 사진의 `src="assets/…"` 부분을 새 파일 이름으로 바꿉니다.
   - 홈 팝업 포스터: `web/index.html`에서 `0347e0270a06ed411387f933b8935339.jpg`를 찾으세요.
   - 사진을 바꾸면 `alt="…"`(사진 설명, 시각장애인용)도 함께 고쳐 주세요.

## 4. 모바일 배치만 바꾸고 싶을 때

글은 PC와 같은 html을 씁니다. 휴대폰(화면 폭 720px 이하)에서만 다르게 보이게 할 배치·크기는 `mobile/mobile.css`에 있습니다.

## 5. 문제가 생기면

- **Actions가 빨간 ✗** → 눌러서 "화면 미리 그리기" 단계의 로그를 보세요. `문제 index.html …`처럼 망가진 파일 이름이 나옵니다.
  이 경우 **배포가 멈추고 기존 사이트가 그대로 유지**되므로 방문자에게는 영향이 없습니다.
- **되돌리기** → 파일을 열고 **History**에서 이전 버전을 확인합니다. 이전 내용을 복사해 다시 붙여 넣고 Commit 하면 됩니다.
- 따옴표·괄호를 실수로 지웠는지가 가장 흔한 원인입니다.

## 6. 내 컴퓨터에서 미리 보기 (선택)

```bash
python3 -m http.server 8000
```

저장소 폴더에서 실행한 뒤 브라우저로 `http://localhost:8000/web/`을 엽니다.
