# 내 도메인으로 사이트 열기 (GitHub Pages)

호스팅은 지금처럼 GitHub Pages(무료)를 그대로 씁니다. 할 일은 **도메인 사기 → 도메인 회사에서 주소 4줄 등록 → GitHub에 도메인 알려 주기** 세 가지입니다.

아래 예시는 도메인이 `comfit.kr`이라고 가정합니다.

## 1. 도메인 사기
가비아, 카페24(국내, 한글 안내), Cloudflare, Namecheap(해외) 등에서 삽니다. `.kr` 기준 1년에 1~2만 원 정도.

## 2. 도메인 회사 화면에서 "DNS 설정(레코드 관리)"
아래를 그대로 추가합니다. 원래 있던 같은 이름의 A / CNAME 레코드(주차 페이지 등)는 지웁니다.

| 종류 | 이름(호스트) | 값 |
|---|---|---|
| A | `@` (비워 두는 곳도 있음) | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `fromistarantino.github.io` |

반영되는 데 몇 분에서 길게는 하루 걸립니다.

## 3. GitHub에 도메인 알려 주기
1. 저장소의 `deploy.json`을 열고 연필(✏️) → `"domain": ""` 을 `"domain": "comfit.kr"` 로 바꾸고 Commit.
   (배포할 때마다 도메인 설정 파일(CNAME)을 자동으로 넣어 줍니다. 이걸 안 하면 배포할 때 도메인이 풀립니다.)
2. 저장소 **Settings → Pages → Custom domain**에 `comfit.kr` 입력 → Save. "DNS check successful"이 뜰 때까지 기다립니다.
3. 같은 화면의 **Enforce HTTPS**에 체크합니다. (자물쇠 주소 https://. 인증서 발급에 최대 하루. 체크 칸이 흐리면 조금 뒤 다시)

## 4. (보안 권장) 도메인 소유 인증
GitHub 오른쪽 위 프로필 → **Settings → Pages → Add a domain** → 안내대로 TXT 레코드를 도메인 회사에 추가 → Verify.
다른 사람이 내 도메인을 자기 GitHub 사이트에 갖다 붙이는 것을 막아 줍니다.

## 5. 확인
- `https://comfit.kr` 과 `https://www.comfit.kr` 이 열리는지
- `https://comfit.kr/join.html` 에서 이벤트 양식이 보이는지 → **광고 링크는 이 주소로**
- 옛 주소(`fromistarantino.github.io/comfit_web_2026/`)는 자동으로 새 도메인으로 넘어갑니다.

이벤트 접수(Google Apps Script)는 도메인과 상관없이 그대로 동작합니다.
